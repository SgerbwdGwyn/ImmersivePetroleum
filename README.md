==============

**Immersive Petroleum** is a Minecraft mod, an addon for Immersive Engineering for 1.20.1. It adds oil, oil extraction, and oil processing to Immersive Engineering's tech progression.

For more information and downloads, see the [CurseForge page](https://minecraft.curseforge.com/projects/immersive-petroleum).

If you are a modpack developer, see the [Wiki](https://github.com/TwistedGate/ImmersivePetroleum/wiki).

Note: I have not developed a minecraft mod since I was 11 years old. This is my first attempt at working with Forge, working with updates, and working with someone else's mod. Pray for me.
